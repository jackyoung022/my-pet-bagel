# Desk Pet

一个 macOS 桌面宠物程序，拥有可爱的动画效果。一个透明的无边框 Electron 窗口常驻在你的屏幕上，可以与活动窗口互动，还能跟随鼠标移动。

## 功能特性

- **透明无边框**：始终置顶的窗口，完美融入桌面
- **丰富动画**：11 种帧动画动作，流畅自然
- **窗口互动**：宠物会跑向活动窗口并钻入窗口顶部边缘
- **鼠标跟随**：通过 `robotjs` 实现全局鼠标跟随
- **右键菜单**：点击宠物打开菜单，手动触发动作
- **智能行为**：空闲时自动打盹，长时间不互动自动钻窗口

## 宠物动作

| 动作 | 触发方式 | 说明 |
|---|---|---|
| **idle** | 静止状态 | 站立不动，四处张望 |
| **waiting** | 静止状态 | 等待动画，与 idle 交替出现 |
| **nap** | 空闲 10 秒 | 长时间不互动时开始打盹 |
| **stretch** | 低概率静止 | 小概率出现的伸懒腰动作 |
| **roll-around** | 菜单 / 随机 | 在地上打滚 |
| **stroke** | 长按（500ms） | 享受被抚摸 |
| **burrow** | 菜单 / 30 秒无操作 | 跑向活动窗口并钻入窗口顶部 |
| **catch-up** | 点击拖拽 | 抓住光标跟随移动 |
| **running-left** | 移动中 | 向左奔跑 |
| **running-right** | 移动中 | 向右奔跑 |
| **jumping-left** | 钻窗口移动 | 向左跳跃到达窗口顶部 |
| **jumping-right** | 钻窗口移动 | 向右跳跃到达窗口顶部 |

### 互动指南

- **右键点击**宠物 → 打开动作菜单（含"跟随鼠标" / "停止跟随"切换）
- **长按宠物** 0.5 秒 → 触发 **stroke**（抚摸）动作
- **点击拖拽** → 宠物跟随鼠标移动（触发 **catch-up**）
- **按住时移开鼠标** → 停止跟随
- **点击**处于钻窗口暂停状态的宠物 → 宠物从窗口边缘跳出
- **移动活动窗口**时宠物处于钻窗口暂停状态 → 宠物自动跳出并恢复空闲

## 技术栈

- **Electron 33** — 跨平台桌面应用框架
- **robotjs** — 主进程全局鼠标位置追踪
- **AppleScript** — 通过 `System Events` 检测活动窗口及最大化状态
- **Canvas 2D** — 底部对齐的逐帧动画渲染

## 前置要求

- macOS
- Node.js 18+
- 授予 Electron 应用辅助功能权限（系统设置 → 隐私与安全性 → 辅助功能）— AppleScript 窗口检测必需

## 安装与运行

```bash
npm install
npm start
```
